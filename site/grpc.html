gRPC 服务参考

以下为 6 个 gRPC 服务自身定义的 RPC（不含跨服务引用用的 client proto）。服务间通过 Consul 服务发现调用， HTTP 入口（shop / admin）见 API 文档。

user 用户服务

:50051 · shop.user.service
方法请求 → 响应说明
GetUserListPageInfo → UserListResponse用户列表
GetUserByMobileMobileRequest → UserInfoResponse通过 mobile 查询用户
GetUserByIdIdRequest → UserInfoResponse通过 Id 查询用户
CreateUserCreateUserInfo → UserInfoResponse创建用户
UpdateUserUpdateUserInfo → Empty更新用户
CheckPasswordPasswordCheckInfo → CheckResponse检查用户密码
ListAddressListAddressReq → ListAddressReply所有收货地址列表
CreateAddressCreateAddressReq → AddressInfo新增收货地址
UpdateAddressUpdateAddressReq → CheckResponse修改收货地址
DefaultAddressAddressReq → CheckResponse设置默认地址
DeleteAddressAddressReq → CheckResponse删除收货地址
GetAddressAddressReq → AddressInfo查询收货地址
