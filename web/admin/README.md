# kratos-shop 运营后台

基于 **Ant Design Pro v6**（Umi Max 4 + React 19 + Ant Design 6）的运营后台。

```bash
npm install
npm run dev
```

开发环境访问 `http://localhost:8000`，`/api/*` 自动代理到 admin BFF（`127.0.0.1:9099`）。

菜单顺序：首页 → 用户管理 → 订单管理 → 商品管理 → 商品分类 → 权限管理，登录后默认进入首页。

- 首页：运营数据看板（用户数、订单量、成交额、近 30 天趋势、订单状态分布、热销商品）
- 用户管理：用户列表、收货地址管理
- 订单管理：列表、详情、发货、退款
- 商品管理：按分类 / 品牌 / SKU 编码搜索，商品详情展示 SKU 与图片，支持新增、上下架、删除
- 商品分类：树形展示分类，支持新增、编辑、删除
- 权限管理：为角色勾选权限点，前端按钮级隐藏（如删除商品、订单退款、删除用户地址）
